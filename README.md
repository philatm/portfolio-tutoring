# Репетитор — Portfolio Site

Single-page portfolio site for a math and English tutor (grades 5–9). Built with plain HTML, CSS, and JS. All content in Russian.

## Structure

```
├── index.html          Main page
├── css/style.css       All styles (BEM)
├── js/main.js          Burger menu, smooth scroll, active nav
    └── img/
        ├── photo.jpg            ← Drop your photo here
        ├── photo-placeholder.svg
        └── favicon.svg          ← The one favicon (Σ)
```

## Setup

Drop your photo into `img/photo.jpg` (800×800 px recommended). The site will fall back to the placeholder SVG until you do.              |

## Tech

- Vanilla HTML/CSS/JS — no build tools needed
- BEM naming
- Responsive: mobile (≤480 px), tablet (≤768 px), desktop
- Colors: `#ffde59` (accent), `#000`, `#fff`

## Deploy

Upload the entire folder to any static host: Netlify, GitHub Pages, Vercel, or any web server.
